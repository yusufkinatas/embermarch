# render agent: done

## Done (`src/render/**` except `camera.ts`, `tests/render/**`, `gallery.html`)
All GDD §A / §P (juice 1-11) / §O minimap / §Q caching scope for the renderer, verified in the browser against
the hand-made fixture, real `generateMap` + `createWorld` worlds for every biome, a live sim battle, and the

| File | What |

| `renderer.ts` | `createRenderer(canvas)` → `CanvasRenderer` (implements `Renderer`). DPR-aware backing store, world transform via `setTransform`, screen shake. Frame order: terrain surface → water shimmer → Blight (+ward edge, tendrils) → live gathered trees → ground fx → selection rings/rally lines → y-sorted entities (shadows, dying units, resources, buildings, ghosts, units) → projectiles → air fx → fog → dusk tint (multiply, `getEncounterView().dusk` × 25%, polled ~4 Hz) → HP bars, placement ghost, targeting → popups/flashes/edge pulse → box select. - `src/game/types.ts`: new `ExtraIconKind` union (ResearchId | 'rally_hearth' | 'house_ability' | 'ability_horn' | 'ability_hymn' | 'ability_firepot' | 'ability_volley' | `ability_${HouseId}` | 'hawk' | 'rally' | 'demolish' | 'stop' | 'hold' | 'attack_move' | `cls_${UnitClass}`) added to `IconKind`; type imports `HouseId`, `ResearchId`, `UnitClass`.

## Performance (Apple M1 Pro, Chromium with GPU canvas, 1920×1080, zoom 0.75, 64×64, 144 units, ~150-200 particles)
- `render()` main-thread cost: avg ~0.7-3 ms, p95 < 6 ms (DPR 1 and 2). Budget 8 ms: met.
- Software-rasterized canvas (headless without GPU): ~20 ms/frame, dominated by the full-screen blits (surface, fog, dusk). One blit was removed by compositing ground + props.
- Terrain cache build ~50-90 ms once per battle (during the Kindle countdown). Headless Chromium throttles rAF to ~13 fps even on an empty page, so use `render()` timings, not fps.

## Deferred / known issues
- The battle shell's `src/game/glyphs.ts` `isIconKind` filter does not yet include the new extra icon keys, so the command card still shows its glyph fallback for research/abilities (battle-shell owns that file; `hasIconArt()` / `EXTRA_ICON_KEYS` are available).
- `gallery.html` is a dev page served by `npx vite`; it is not in the production build (vite.config.ts is not mine).
- Changing DPR across the 1.5 threshold mid-battle rebuilds the terrain cache and drops painted rubble/scorch decals.
- `ctx.filter` blur for the soft fog/Blight needs a browser that supports canvas filters (Chrome/Firefox, Safari 18); elsewhere edges are just bilinear-smoothed.
